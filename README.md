# Турбо-Суслик 2.0: Mainstream Edition

**Дмитрий Леушкин**

Турбо-Суслик представляет собой систему самостоятельной работы с устойчивыми эмоциональными реакциями, убеждениями, страхами, внутренними конфликтами и повторяющимися поведенческими паттернами.

Для работы используются структурированные текстовые инструкции, которые называются **протоколами**.

Идея системы не в том, чтобы заменить «плохие» мысли «хорошими». Протокол используется для обработки воспоминаний, эмоций, убеждений, телесных реакций и связанных с ними элементов, которые продолжают поддерживать старую реакцию.

Основная идея проста:

**прошлое может остаться в памяти, не продолжая управлять настоящим.**

## Зачем это нужно?

Человек может прекрасно понимать свою проблему и всё равно продолжать автоматически реагировать по-старому.

Можно знать, что событие давно закончилось, страх нерационален, а убеждение бессмысленно, однако тело, эмоции и поведение продолжают запускать тот же сценарий.

Турбо-Суслик работает именно с этим автоматическим уровнем.

Задача не в том, чтобы установить новую систему убеждений, а в том, чтобы уменьшить управляющую силу старого материала и получить больше свободы в реакции.

## Как это работает?

Протокол указывает, какой материал нужно обработать, и задаёт системе структурированную инструкцию для работы с ним.

В самом простом виде:

`старый материал → протокол → обработка → снижение автоматической реакции`
